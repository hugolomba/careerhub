# CareerHub — Starter Scaffold

Scaffold inicial para o projeto de final de curso CareerHub (React + Spring Boot + PostgreSQL), baseado no Project Proposal, Project Requirements Specification e Interim Progress Report submetidos.

Comece pelo arquivo **[GUIA_INICIO.md](./GUIA_INICIO.md)** — ele explica o que já está pronto, como rodar tudo, e a ordem recomendada para implementar o resto das features.

Estrutura:

```
careerhub-starter/
├── backend/    # Spring Boot: entidades, migrations, JWT auth funcional
├── frontend/   # React (Vite): login/register/dashboard, cliente com JWT
├── docker-compose.yml   # Postgres local
└── GUIA_INICIO.md
```
